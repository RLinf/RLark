## Becoming a Maintainer

RLark follows the [Contributor Covenant](https://www.contributor-covenant.org/) and welcomes contributions from the community. Maintainers are selected from active contributors who demonstrate:

- Sustained, high-quality contributions to the project
- Deep understanding of the codebase and architecture
- Active participation in code reviews and community discussions
- Commitment to the project's values and community standards

To nominate a new maintainer, open a discussion in the repository.

## Maintainer Responsibilities

- Review and merge pull requests
- Triage issues and feature requests
- Maintain documentation and release notes
- Ensure code quality and test coverage
- Uphold the Code of Conduct
