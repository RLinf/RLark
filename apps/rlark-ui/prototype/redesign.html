集群管理

新建集群

给出新场地的名字和第一台机器的 SSH。RLark 登录这台机器，把它做成新场地的第一台 Hub 和新集群的控制面，装好集群 agent、Station 和插件，最后跑一个验收 Job。

01

场地与身份

集群类型决定默认集群名与后续节点的入网方式。场地名会成为 Hub 与隧道地址的一部分。

集群类型 *
隧道公网端点 选填 几台机器共用一个公网 IP 时填写云上转发给这台的地址；留空则使用 机器IP:51820。
02

第一台机器

这台机器将成为场地的第一台 Hub 与集群控制面。机器需要 systemd、tar 和 WireGuard 内核模块。

将要创建

rlark-<site>-<type>

—

类型—
场地—
集群—
第一台机器—
隧道端点—
  • 把机器做成控制面
  • 安装场地的第一台 Hub
  • 安装集群 agent 与 Station
  • 跑一个验收 Job

口令只用于这一次，不保存。建好之后，其他机器用入网码或 SSH 加入这个集群。
