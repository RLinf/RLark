# 管理员指南

管理员负责部署和运维 RLark 控制面、纳管数据面集群、管理 Agent 与节点资源，并维护网络、安全和具身设备集成。首次体验请先完成[快速开始](../quickstart.md)，生产环境相关决策以本节为准。

日常、低频操作优先说明管理平台 UI；批量纳管、升级和配置变更同时提供 CLI 或 API 路径。自动化接口的精确参数以[参考手册](../reference/index.md)为准。
