# Administrator Guide

Administrators deploy and operate the RLark control plane, onboard data-plane clusters, manage Agents and node resources, and maintain networking, security, and embodied-device integrations. For a first evaluation, follow the [Quick Start](../quickstart.md); use this section for production decisions.

Routine and low-frequency operations lead with the administrator UI; bulk onboarding, upgrades, and configuration changes also provide CLI or API paths. Exact automation interfaces belong in the [Reference](../reference/index.md).
