# Developer Guide

This section is for contributors changing RLark itself. Read the [Project Layout](project-layout.md) and [Technical Architecture](../architecture.md), then set up [Local Development](local-development.md). Product deployment and cluster onboarding belong in the [Administrator Guide](../admin-guide/index.md).

Developer documentation is API-, CRD-, CLI-, source-, and debugging-first and does not depend on Web UI screenshots. User-facing capabilities must keep UI and API semantics aligned.
